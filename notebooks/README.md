# Minter API Test Notebooks

This folder contains a complete end-to-end notebook plus feature-focused notebooks.

## Notebook Index

- `minter_api_test.ipynb`
  - Full end-to-end functional flow (original consolidated notebook).

- `minter_01_smoke_authority.ipynb`
  - Service smoke checks (`/health`, `/worker/status`) and authority endpoint checks.

- `minter_02_reserve_validation.ipynb`
  - Single reserve/get lifecycle, malformed ARK checks, unauthorized reserve checks, checkdigit mutation behavior.

- `minter_03_update_metadata_formats.ipynb`
  - `RESERVED -> DRAFT`, `DRAFT -> DRAFT` overwrite, validation errors, JSON and XML metadata paths.

- `minter_04_tombstone_missing.ipynb`
  - Tombstone lifecycle (`DRAFT -> TOMBSTONE`), delete idempotency, blocked updates on tombstoned ARKs, missing-record update/delete behavior.

- `minter_05_batch_concurrency.ipynb`
  - Batch reserve success/failure paths and parallel reserve uniqueness checks.

- `minter_06_worker_publish_update.ipynb`
  - Worker-driven transitions (`DRAFT -> PUBLISHED`, `PUBLISHED -> UPDATE -> PUBLISHED`).

- `minter_07_chain_import_optional.ipynb`
  - Optional local import path for pre-existing on-chain ARKs (`EXISTING_CHAIN_ARK`).

## Shared Environment Variables

All notebooks read the same runtime variables from the first setup cell:

- `MINTER_BASE_URL` (default: `http://localhost:8001`)
- `ADMIN_API_URL` (default: `http://localhost:8000/api/v1/admin`)
- `AUTHORITY_ID` (default: autogenerated)
- `NAAN` (default: `12345`)
- `REGISTER_AUTHORITY` (default: `true`)
- `EXISTING_CHAIN_ARK` (default: empty; used only in `minter_07_chain_import_optional.ipynb`)
- `POLL_INTERVAL_SECONDS` (default: `2`)
- `POLL_TIMEOUT_SECONDS` (default: `90`)

## Execution Notes

- Most notebooks include the authority bootstrap step; if you already have an authorized authority, set:
  - `REGISTER_AUTHORITY=false`
  - `AUTHORITY_ID=<existing-authorized-uuid>`
- Worker-specific checks in `minter_06_worker_publish_update.ipynb` require the standalone worker to be running.
- Each notebook prints a final pass/fail summary and raises an assertion if any check fails.
